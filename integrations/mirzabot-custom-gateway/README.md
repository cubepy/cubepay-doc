# 🔗 اتصال CubePay به «درگاه پرداخت سفارشی» میرزابات

این راهنما برای فروشنده‌هاییه که از **نسخه‌ی پولی/جدید میرزابات** استفاده می‌کنن — همون‌جایی که به‌جای درگاهِ از پیش‌ساخته، یه بخش به اسم **«مالی ← تنظیمات درگاه سفارشی»** داره و ازتون یه آدرس API می‌خواد.

> 📌 اگه از نسخه‌ی رایگان/عمومیِ میرزابات استفاده می‌کنید، CubePay از قبل داخلش هست و به این راهنما نیازی ندارید — [راهنمای اون نسخه](../mirzabot-ready-files/mirzabot-ready-files-guide.md).

با این فایل، ربات‌تون بدونِ هیچ تغییری در کدِ خودش به CubePay وصل می‌شه و **هم کارت‌به‌کارت و هم ارز دیجیتال** رو پشتیبانی می‌کنه.

---

## 🧭 این وسط چه اتفاقی می‌افتد؟

```
مشتری «پرداخت» می‌زند
      ↓
ربات → cubepay-gateway.php  (روی هاستِ خودتان)
      ↓
      → CubePay: یک فاکتور بساز
      ← لینک پرداخت
      ↓
ربات لینک را به مشتری نشان می‌دهد → مشتری پرداخت می‌کند
      ↓
CubePay → cubepay-gateway.php  (کال‌بک)
      ↓
      → از CubePay دوباره می‌پرسد: واقعاً پرداخت شده؟
      ↓ بله
      → ربات: این سفارش پرداخت شد، سرویس را فعال کن
```

🔒 نکته‌ی امنیتیِ مهم: این واسط **هیچ‌وقت به خودِ کال‌بک اعتماد نمی‌کند**. کال‌بک به یک آدرسِ عمومی می‌رسد و هر کسی می‌تواند یک درخواستِ جعلی بفرستد، پس تصمیمِ نهایی همیشه بر اساسِ استعلامِ مستقیم از CubePay گرفته می‌شود.

---

## ✅ نصب در ۴ قدم

### قدم ۱ — فایل را روی هاستِ خودتان بگذارید

فایل [`cubepay-gateway.php`](./cubepay-gateway.php) را دانلود و روی هاستِ خودتان آپلود کنید، مثلاً:

```
https://yourdomain.com/cubepay-gateway.php
```

> می‌تواند همان هاستِ ربات باشد یا هر هاستِ دیگری — فقط باید از اینترنت با HTTPS در دسترس باشد.

### قدم ۲ — بالای فایل را پر کنید

```php
const BOT_BASE_URL   = 'https://yourbot.com';   // آدرس رباتِ خودتان
const BOT_TOKEN2     = '...';                   // با دستور /token2 در ربات می‌گیرید
const BRIDGE_API_KEY = '...';                   // یک رشته‌ی تصادفیِ دلخواه بسازید
const CUBEPAY_TOKEN  = '...';                   // از @cubepy_bot ← «🔗 پنل من»
```

برای ساختِ یک رشته‌ی تصادفیِ خوب: در ترمینال `openssl rand -hex 32`، یا هر رمزِ بلندِ تصادفی.

### قدم ۳ — تنظیماتِ ربات

در ربات خودتان: **مالی ← تنظیمات درگاه سفارشی**

| فیلد | مقدار |
|---|---|
| آدرس API | `https://yourdomain.com/cubepay-gateway.php` |
| توکن API | همان چیزی که در `BRIDGE_API_KEY` گذاشتید |

⚠️ «توکن API» اینجا **ربطی به توکنِ CubePay ندارد** — فقط رمزِ بینِ رباتِ شما و همین فایل است.

### قدم ۴ — تست

یک خریدِ کوچک (مثلاً ۱۰,۰۰۰ تومان) در رباتِ خودتان بزنید. باید:

1. لینکِ پرداخت باز شود (کارت‌به‌کارت، یا صفحه‌ی «کارت یا کریپتو؟» اگر هر دو را فعال کرده باشید)
2. بعد از واریز، چند ثانیه بعد خودکار تایید شود
3. رباتِ شما سرویس/شارژ را خودکار تحویل بدهد

## 🩺 اگر کار نکرد

فایل خودش لاگ می‌گیرد: `cubepay-orders/gateway.log` کنارِ همان فایل. اولین جایی که باید نگاه کنید همین است.

| نشانه | علتِ محتمل |
|---|---|
| ربات می‌گوید «خطا در ساخت لینک پرداخت» | `CUBEPAY_TOKEN` اشتباه است، یا حسابتان هنوز تایید نشده |
| در لاگ: `invalid api_key` | «توکن API» در تنظیماتِ ربات با `BRIDGE_API_KEY` یکی نیست |
| پرداخت انجام می‌شود ولی سرویس فعال نمی‌شود | `BOT_TOKEN2` یا `BOT_BASE_URL` اشتباه است — در لاگ دنبالِ `bot notify failed` بگردید |
| در لاگ: `not verified` | CubePay هنوز پرداخت را تایید نکرده (مبلغِ واریزی دقیق نبوده، یا پیامکِ بانکی نرسیده) |

برای عیب‌یابیِ مسیرِ پیامک، در `@cubepy_bot` از «🧪 تست اتصال ← 🧪 تست پیامک (فوروارد)» و «🧪 تست وب‌هوک» استفاده کنید.

## ❓ سوال‌های رایج

**چند لینک هم‌زمان (کارت و کریپتو جدا) می‌خواهم.**
لازم نیست — CubePay خودش این کار را می‌کند. اگر در «💳 روش‌های پرداخت» هر دو را فعال کنید، مشتری یک صفحه‌ی «کارت یا کریپتو؟» می‌بیند و خودش انتخاب می‌کند.

**مبلغ‌ها ریال است یا تومان؟**
رباتِ میرزا مبلغ را به **تومان** می‌فرستد و این واسط هم همان را به endpointِ تومانیِ CubePay می‌دهد. نیازی به تبدیل نیست.

**چرا بعد از پرداخت به سایتم برنمی‌گردد؟**
عمدی است: این واسط `redirect_after_payment: false` می‌فرستد، چون فروش از طریقِ رباتِ تلگرام است و نتیجه را خودِ ربات به مشتری می‌گوید. اگر ریدایرکت می‌خواهید، آن خط را در فایل به `true` تغییر دهید.

**می‌خواهم به‌جای گوشیِ خودم، CubePay تسویه کند.**
این همان 👑 **CubePay VIP** است. شرطِ ورود: حداقل ۳۰ روز سابقه‌ی حساب و ۳۰ تراکنشِ تاییدشده. جزئیات در [مرجعِ VIP](../../docs/CUBEPAY-VIP-API-REFERENCE.md). بعد از فعال‌سازی، فقط کافی است `CUBEPAY_TOKEN` را با توکنِ `vip_…` عوض کنید — هیچ تغییرِ دیگری در این فایل لازم نیست.
