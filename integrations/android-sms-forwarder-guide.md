# 🤖 اتصال پیامک بانکی از اندروید — اپلیکیشن اختصاصی CubePay SMS Forwarder

علاوه بر اپ‌های عمومی «SMS Forwarder» که تو FAQ بهشون اشاره شده، یه
**اپلیکیشن اختصاصی CubePay** هم برای اندروید داریم — از قبل برای فرمت
وب‌هوک CubePay تنظیم شده، سبک‌تره، و نیازی به تنظیمات اضافه (فیلتر
پیامک، فرمت Body و…) نداره.

> این روش روی سیم‌کارتی که پیامک بانک روش میاد اجرا می‌شه — باید یه
> گوشی اندرویدی داشته باشید که پیامک بانکتون روش دریافت می‌شه، همیشه
> روشن و متصل به اینترنت بمونه.

---

## پیش‌نیاز

از پنل حساب («⚙️ تنظیمات بیشتر → 📲 روش تاییدیه مبلغ واریزی») روش
«🔗 وب‌هوک» رو انتخاب کنید و آدرس وب‌هوک اختصاصی خودتون رو کپی کنید —
چیزی شبیه این:

```
https://cubevps.ir/smspay/webhook/sms.php?secret=XXXXXXXXXXXXXXXXXXXXXXXX
```

## دانلود و نصب

📥 **[دانلود CubePay SMS Forwarder (APK)](https://cubevps.ir/downloads/cubepay.apk)**

🔒 **SHA-256:** `452921c465b5e2d3e41d178d9ffa45c1efb4dd0e9066cfa56cb96aed5bc85e18`
(هش فایل دانلودی رو با این مقدار مقایسه کنید تا مطمئن بشید فایل
دستکاری نشده — از هر ابزار محاسبه‌ی SHA-256 روی گوشی یا کامپیوترتون
می‌تونید استفاده کنید.)

چون این اپ از گوگل‌پلی نصب نمی‌شه، اندروید موقع نصب هشدار «منبع ناشناس»
می‌ده — این طبیعیه:

1. فایل `cubepay.apk` رو دانلود کنید.
2. روی فایل دانلودشده بزنید تا نصب شروع بشه؛ اگه پیام «برای امنیت شما،
   گوشی از نصب اپ‌های ناشناس جلوگیری می‌کنه» اومد، رو **تنظیمات** بزنید
   و اجازه‌ی نصب از همون مرورگر/فایل‌منیجر رو فعال کنید، بعد برگردید و
   نصب رو ادامه بدید.
3. بعد از نصب، اپ رو باز کنید و **دسترسی خواندن پیامک (SMS)** رو تایید
   کنید — بدون این دسترسی، اپ نمی‌تونه پیامک بانکی رو ببینه.

## تنظیم آدرس وب‌هوک

1. تو اپ، وارد بخش **تنظیمات → آدرس مقصد (Webhook URL)** بشید.
2. دقیقاً همون آدرس وب‌هوکی که از پنل حساب کپی کردید (بخش «پیش‌نیاز»
   بالا) رو وارد کنید.
3. ذخیره کنید.

## نکته‌ی مهم اندروید: بهینه‌سازی باتری رو خاموش کنید

بر خلاف iOS، اندروید معمولاً اپ‌هایی که مدتی تو پس‌زمینه بی‌کار بمونن
رو برای صرفه‌جویی باتری می‌کشه — این یعنی ممکنه اپ فورواردر بعد از چند
ساعت دیگه پیامک رو نبینه، مگر این کار رو انجام بدید:

- برید به **تنظیمات گوشی → باتری/مصرف باتری → CubePay SMS Forwarder**
  و گزینه‌ی «بدون محدودیت» یا «Unrestricted» (بسته به برند گوشی: Battery
  saver exception / Auto-start / App standby) رو براش فعال کنید.
- بعضی برندها (شیائومی، هواوی، سامسونگ و…) یه لایه‌ی مدیریت باتری
  اضافه دارن — تو تنظیمات همون برند هم دنبال «Auto-start» یا
  «Protected apps» بگردید و اپ رو اضافه کنید.

بدون این تنظیم، ممکنه گاهی پیامک بانکی با تاخیر یا اصلاً به سیستم
نرسه، حتی اگه گوشی روشن و به اینترنت وصل باشه.

## تست کنید

یه فاکتور آزمایشی (Sandbox) یا واقعی با مبلغ کم بسازید، از کارت واقعی
واریز کنید، و ببینید طی چند ثانیه پیامک بانک می‌رسه و فاکتور خودکار
تایید می‌شه. برای دیباگ، از دکمه‌ی «🧪 تست اتصال پیامک» تو پنل حساب
استفاده کنید.

## 🆘 اگه اپ جواب نداد

- مطمئن بشید دسترسی SMS رو رد نکرده باشید (تو تنظیمات اندروید:
  **برنامه‌ها → CubePay SMS Forwarder → مجوزها**).
- بهینه‌سازی باتری رو دوباره چک کنید (بخش بالا).
- آدرس وب‌هوک رو دوباره از پنل کپی و جایگزین کنید — ممکنه موقع کپی،
  فاصله یا کاراکتر اضافه وارد شده باشه.
- اگه بازم جواب نداد، از اپ‌های عمومی «SMS Forwarder» (که تو
  [docs/FAQ.md](../docs/FAQ.md) بهشون اشاره شده) به‌عنوان جایگزین
  استفاده کنید — تنظیماتشون مشابهه: مقصد فوروارد رو رو **URL** بذارید و
  همون آدرس وب‌هوک رو وارد کنید.
- یا از طریق [cube_sup](https://t.me/cube_sup) بپرسید.
