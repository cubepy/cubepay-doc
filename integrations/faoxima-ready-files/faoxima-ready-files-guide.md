# 📦 اتصال آماده‌ی CubePay به ربات Foxima (نصب با فایل، نه ویرایش دستی)

این راهنما برای فروشنده‌هاییه که ربات فروش‌شون رو با کد **Foxima** (یا فورک‌های مشابه) ساختن. به‌جای این‌که خودتون خط‌به‌خط کد رو ویرایش کنید، فقط این فایل‌های آماده رو جایگزین کنید — سریع‌تر و بی‌خطاتر.

🆕 **این نسخه از پرداخت با ارز دیجیتال (USDT / TRX / TON) هم پشتیبانی می‌کنه** — اگه رو حساب فروشندگیِ خودتون تو ربات CubePay («⚙️ تنظیمات بیشتر → 💳 روش‌های پرداخت») کریپتو رو هم فعال کنید، مشتری‌هاتون موقع پرداخت بین کارت و کریپتو انتخاب می‌کنن؛ اگه فقط کارت رو فعال نگه دارید، دقیقاً مثل قبل کار می‌کنه.

⚠️ **قبل از شروع:** یه نسخه پشتیبان (بک‌آپ) از پوشه‌ی ربات‌تون بگیرید. این فایل‌ها **کامل جایگزین** فایل‌های فعلی می‌شن؛ اگه قبلاً خودتون تغییری تو همین ۵ فایل داده باشید، از دست می‌ره.

---

## 🔴 بخش ۱ — فایل‌های اجرایی (اجباری، بدون این‌ها CubePay اصلاً کار نمی‌کنه)

| فایل | مسیر جایگزینی |
|---|---|
| `business_logic_1.php` | `re/rx/function/business_logic_1.php` |
| `successful.php` | `payment/ZarinPay/successful.php` |
| `database_helpers_2.php` | `re/rx/function/database_helpers_2.php` |
| `bot_api_helpers.php` | `re/rx/function/bot_api_helpers.php` |

دو فایل اول، **قلب اتصال** به CubePay‌ان — ساخت فاکتور و تایید پرداخت رو انجام می‌دن. هیچ اطلاعات شخصی‌ای (توکن، رمز) توشون نیست؛ توکن رو جدا از تو ربات (توضیح در ادامه) وارد می‌کنید.

دو فایل بعدی روی یه نصبِ واقعی لازم شدن و از این به بعد جزو مجموعه‌ان:

- `database_helpers_2.php` — **کسر کیف‌پول رو اتمیک و «حداکثر یک‌بار» می‌کنه.** روی هاست‌های اشتراکیِ شلوغ دیده شد که پروسه گاهی وسطِ کارِ بعد از پرداخت کشته می‌شه؛ بدون این فایل، سرویس ساخته می‌شد ولی سهمِ کیف‌پولِ خریدار کسر نمی‌شد و گزارشِ خرید هم به کانال نمی‌رفت. حالا هر پرداخت با مارکر ردیابی می‌شه و `successful.php` جدید هم هر سفارشِ نیمه‌کاره‌ی قبلی رو خودکار تکمیل می‌کنه (بازیابی). **این دو فایل مکمل هم‌ان — یا هر دو رو جایگزین کنید یا هیچ‌کدوم.**
- `bot_api_helpers.php` — یه گلوگاه سنگین پردازش تصویر (۲۲ بار بلور برای پس‌زمینه‌ی QR) رو ~۴۰ برابر سریع کرده. روی هاست اشتراکی، همین گلوگاه باعث می‌شد تحویلِ سرویس وسط راه کشته بشه.

📄 بعد از نصب، یه لاگ عیب‌یابی هم کنار `successful.php` ساخته می‌شه (`payment/ZarinPay/cubepay-callback.log`) که اگه مشکلی پیش اومد، قدم‌به‌قدم نشون می‌ده کار کجا متوقف شده — موقع تماس با پشتیبانی همین فایل رو بفرستید. خودش می‌چرخه و بزرگ‌تر از ~۱MB نمی‌شه.

⚠️ اگه نسخه‌ی Foxima شما جدیدتره یا خودتون این فایل‌ها رو شخصی‌سازی کردید، جایگزینیِ کامل تغییراتتون رو می‌پرونه — تو این حالت به‌جای جایگزینی، از [@cubepy_bot](https://t.me/cubepy_bot) کمک بگیرید تا پچ روی نسخه‌ی خودتون اعمال بشه.

## 🔵 بخش ۲ — فایل‌های ظاهری/کیبورد (اختیاری، فقط برای حذف اسم «زرین‌پی»)

| فایل | مسیر جایگزینی |
|---|---|
| `bootstrap_1.php` | `re/rx/admin/bootstrap_1.php` |
| `bootstrap_2.php` | `re/rx/admin/bootstrap_2.php` |
| `layouts_1.php` | `re/rx/keyboard/layouts_1.php` |
| `settings.php` | `re/rx/admin/settings.php` |
| `service_keyboard.php` | `panel/service_keyboard.php` |

این پنج‌تا فقط **متن دکمه‌ها** (تو چت ادمین ربات و تو پنل وب) رو از «زرین پی» به «کیوب پی» تغییر می‌دن — هیچ منطقی رو عوض نمی‌کنن. اگه اسم «زرین پی» تو پنل ادمین خودتون براتون مهم نیست، می‌تونید این ۵ فایل رو اصلاً جایگزین نکنید — CubePay بدون‌شون هم درست کار می‌کنه.

📌 **یه نکته‌ی جدا از اسم:** فایل `bootstrap_2.php` یه چیز دیگه هم داره — دکمه‌ی «آموزش اتصال» تو نسخه‌ی اصلی Foxima، پیام و **لینک تماس شخصی سازنده‌ی اولیه‌ی زرین‌پی** رو نشون می‌ده (نه شما، نه CubePay). اگه دوست ندارید مشتری‌هاتون یه لینک تماس ناشناس ببینن، پیشنهاد می‌کنم این یکی رو حتی اگه به اسم «زرین‌پی» حساس نیستید، جایگزین کنید.

📌 **یه قدم SQL هم لازمه** (اگه بخش ۲ رو جایگزین می‌کنید): یه اسم دیگه‌ی «زرین پی» تو خود دیتابیس ذخیره شده (نه تو فایل)، که هم رو دکمه‌ی خرید مشتری هم رو یه لیست تو پنل وب اثر می‌ذاره. این یه خط رو تو phpMyAdmin (تب SQL) بزنید:

```sql
UPDATE textbot SET text = '🟠 کیوب پی' WHERE id_text = 'zarinpey';
```

## 🤖 نصب خودکار با `install.php` (اختیاری، به‌جای قدم ۲ و ۴)

به‌جای این‌که فایل‌ها رو دستی آپلود کنید و بعد از داخل ربات توکن بزنید، می‌تونید از
`install.php` (همین پوشه) استفاده کنید — یه ویزارد که هم از مرورگر (هاست اشتراکی/cPanel)
و هم از خط فرمان (`php install.php` — سرورهایی که SSH/VPS دارن) قابل اجراست، و کارهای
زیر رو خودش انجام می‌ده:

- بک‌آپ گرفتن از فایل‌های فعلی قبل از جایگزینی
- کپی فایل‌های بخش ۱ (و در صورت انتخاب، بخش ۲) تو مسیرهای درست
- ثبت مستقیم توکن API، وضعیت فعال/غیرفعال، و متن دکمه تو دیتابیس ربات (بدون نیاز به
  ورود دستی از داخل تلگرام یا زدن SQL تو phpMyAdmin)

### نحوه‌ی استفاده

1. **قبل از آپلود**، فایل `install.php` رو باز کنید و مقدار `INSTALL_PASSWORD` رو به یه
   رمز دلخواه تغییر بدید — تا وقتی مقدار پیش‌فرضه، اسکریپت اصلاً اجرا نمی‌شه.
2. فایل رو کنار بقیه‌ی فایل‌های همین پوشه (`business_logic_1.php`, `successful.php`, ...)
   آپلود کنید (هر جایی از هاست‌تون، لازم نیست تو ریشه‌ی ربات باشه).
3. **هاست اشتراکی/cPanel**: آدرس فایل رو تو مرورگر باز کنید و فرم رو پر کنید (مسیر کامل
   ریشه‌ی ربات، توکن API، فعال/غیرفعال، اطلاعات دیتابیس از `config.php` ربات‌تون).
   **VPS با SSH**: بزنید `php install.php` و به سوال‌های تعاملی جواب بدید.
4. بعد از پیام موفقیت، همون لحظه فایل `install.php` رو از روی سرور پاک کنید — دکمه‌ی
   «حذف خودکار همین فایل» تو صفحه‌ی موفقیت هم هست.

⚠️ این اسکریپت فقط فایل‌های همین لیست رو جایگزین می‌کنه و فقط مقادیر شناخته‌شده‌ی
`PaySetting.token_zarinpey` / `PaySetting.zarinpeystatus` / `textbot.zarinpey` رو تو
دیتابیس می‌نویسه — هیچ کوئری دلخواه دیگه‌ای اجرا نمی‌کنه. با این‌حال چون رمز عبور دیتابیس
رو مستقیم از شما می‌گیره، حتماً رمز نصب رو عوض کنید و فایل رو بعد از اتمام کار پاک کنید.

اگه ترجیح می‌دید همه‌چیز رو دستی و قدم‌به‌قدم انجام بدید (یا اسکریپت با فورک شما جواب
نداد)، از قدم‌های زیر استفاده کنید — دقیقاً همون کاری رو انجام می‌دن که `install.php`
خودکار می‌کنه.

## ✅ قدم‌های نصب دستی

### قدم ۱ — بک‌آپ
از پوشه‌ی ربات‌تون یه کپی بگیرید.

### قدم ۲ — جایگزینی فایل‌ها
بسته به این‌که فقط بخش ۱ رو می‌خواید یا هر ۵ تا رو، فایل‌ها رو دقیقاً تو همون مسیرهای بالا جایگزین کنید.

### قدم ۳ — ثبت‌نام تو CubePay
اگه هنوز فروشنده نشدید، به [@cubepy_bot](https://t.me/cubepy_bot) پیام بدید و ثبت‌نام کنید (نام کسب‌وکار، شماره تلفن، تایید قوانین). بعد از تایید ادمین، از «🔗 پنل من» توکن API‌تون رو بردارید.

### قدم ۴ — وارد کردن توکن تو ربات خودتون
تو ربات خودتون (Foxima)، برید:

```
پنل مدیریت → درگاه‌های ریالی → زرین‌پی (یا کیوب‌پی، اگه بخش ۲ رو هم جایگزین کردید)
```

و این‌ها رو تنظیم کنید:
- ✅ فعال‌سازی: روشن
- 🔑 توکن: همونی که از CubePay گرفتید
- (اختیاری) حداقل/حداکثر مبلغ، کش‌بک

### قدم ۵ — تنظیم کارت و وب‌هوک پیامک تو CubePay
تو `@cubepy_bot`:
- «💳 مدیریت کارت‌ها» → کارت خودتون رو اضافه کنید
- «📲 آموزش اتصال پیامک» → اپ فورواردر رو رو گوشی خودتون طبق راهنما تنظیم کنید

⚠️ **یادتون نره:** گوشی‌ای که این اپ روشه باید همیشه به اینترنت وصل باشه، وگرنه هیچ تراکنشی تایید نمی‌شه.

### قدم ۶ — (اختیاری) فعال‌سازیِ ارز دیجیتال
اگه می‌خواید مشتری‌هاتون گزینه‌ی کریپتو رو هم ببینن، تو ربات CubePay: **«⚙️ تنظیمات بیشتر → 💳 روش‌های پرداخت»** → کریپتو رو فعال کنید (و از «💰 ولت پرداخت کریپتو» آدرس دریافتی‌تون رو ثبت کنید). اگه فقط کارت رو فعال نگه دارید، نیازی به این قدم نیست.

### قدم ۷ — تست
یه شارژ کیف‌پول کوچیک (مثلاً ۱۰,۰۰۰ تومان) تو ربات خودتون امتحان کنید. باید:
1. لینک پرداخت باز بشه — اگه فقط کارت فعاله مستقیم صفحه‌ی کارت، اگه هر دو فعاله اول صفحه‌ی «کارت یا کریپتو؟»
2. بعد از واریز (کارتی یا کریپتویی)، چند ثانیه‌ای خودکار تایید بشه
3. ربات‌تون سرویس/شارژ رو خودکار تحویل بده

## ❓ اگه فایل‌ها جواب نداد

اگه بعد از جایگزینی خطا گرفتید، احتمالاً نسخه‌ی Foxima شما با نسخه‌ای که این فایل‌ها ازش گرفته شده فرق داره (مثلاً قبلاً خودتون یه‌جای دیگه‌ی همین فایل‌ها رو دستی تغییر داده بودید). تو این حالت:
- بک‌آپ رو برگردونید
- به‌جای این فایل‌ها، از **[راهنمای ویرایش دستی](../faoxima-integration-guide.md)** استفاده کنید — همون خطوطِ مشخص رو تو فایل خودتون تغییر بدید، بدون این‌که کل فایل عوض بشه

اگه بازم گیر کردید، `error_log` کنار فایل‌های PHP رو بفرستید تا دقیق بررسی بشه.
