# 📱 اتصال پیامک بانکی از آیفون (iOS Shortcuts)

روی آیفون با یک **شورتکاتِ آماده** می‌تونی پیامک‌های واریزِ بانکی رو خودکار به CubePay بفرستی تا فاکتورها لحظه‌ای تایید بشن — بدونِ هیچ اپِ جانبی.

> ⚠️ **این روش دو تیکه‌ست و هر دو اجباری‌ان:**
> **۱) شورتکاتِ آماده** (پیامک رو می‌فرسته) + **۲) یک Automation** (خودکار اجراش می‌کنه).
> **بدونِ Automation هیچ‌چیز کار نمی‌کنه** — شورتکات به‌تنهایی هیچ‌وقت خودش راه نمی‌افته.

> 📱 گوشی‌ای که این روش روشه باید **همیشه روشن و به اینترنت وصل** باشه (پیامکِ بانک روی همون گوشی میاد).

---

## گام ۱ — شورتکاتِ آماده رو نصب کن

۱. رو آیفون این لینک رو باز کن: **[افزودن شورتکاتِ CubePay](https://www.icloud.com/shortcuts/a22472a5fe254bb6a4c39414d490f2c0)** ← **Add Shortcut**.
۲. شورتکات به لیستت اضافه می‌شه. انگشتت رو روش نگه دار (یا سه‌نقطه‌ی بالاش) ← **Edit**.
۳. توی اکشنِ **Get Contents of URL**، آخرِ آدرس نوشته `PASTE_YOUR_CODE_HERE`. فقط همون رو پاک کن و **کدِ اتصالِ خودت** رو جاش بذار (کد رو از ربات، بخشِ «📲 روش تاییدیه مبلغ واریزی» می‌گیری). آدرسِ نهایی باید این بشه:
   `https://cubevps.ir/smspay/webhook/sms.php?secret=کدِ‌شما`
۴. بالا سمت راست **Done**.

## گام ۲ — Automation بساز ⚠️ (بدونِ این، هیچی کار نمی‌کنه)

۱. اپ **Shortcuts** ← تب **Automation** ← **+** ← **Create Personal Automation**.
۲. نوعِ ماشه رو انتخاب کن (**اسمش بسته به نسخه‌ی iOS فرق می‌کنه**):
   - **iOSِ جدید:** **When I receive a message** — یه فیلترِ **Sender** داره که **اجباریه**؛ روش بزن و **شماره/سرشماره‌ی بانکت** (همونی که پیامکِ واریز ازش میاد) رو بذار، وگرنه فعال نمی‌شه.
   - **iOSِ قدیمی‌تر:** **When I Get a Message Containing…** (فیلترها اختیاری‌ان، می‌تونی خالی بذاری).
۳. **اکشنش رو همین شورتکاتِ CubePay** بذار (Run Shortcut).
۴. بالای صفحه **Ask Before Running** رو **خاموش** کن و ذخیره کن.

## تست

یه فاکتور بساز و مبلغِ کمی واریز کن؛ باید چند ثانیه بعد خودکار تایید بشه. برای عیب‌یابی، دکمه‌ی **«🧪 تست اتصال پیامک»** توی ربات هست.

---

## 🆘 فقط اگه شورتکاتِ آماده باز نشد — ساختِ دستی

اگه لینکِ آماده به هر دلیلی باز نشد، خودت شورتکات رو بساز. توی همون Automationِ گامِ ۲، به‌جای انتخابِ شورتکاتِ آماده:

۱. **Add Action** ← **Get Contents of URL** رو اضافه کن، آدرس: `https://cubevps.ir/smspay/webhook/sms.php`
۲. روی فلشِ **Show More** بزن ← **Method: POST** و **Request Body: Form**.
۳. **دو فیلد** اضافه کن (هر بار نوعِ **Text**):
   - `secret` = کدِ اتصالِ خودت
   - `text` = متغیرِ **Shortcut Input** (تایپ نکن؛ از نوارِ بالای کیبورد انتخابش کن تا **آبی** بشه)
۴. **Ask Before Running** رو خاموش کن و ذخیره کن.

> 🚫 دو اشتباهِ رایج: (۱) `Shortcut Input` رو دستی تایپ کردن به‌جای انتخاب از نوار (برچسب باید **آبی** باشه). (۲) گذاشتنِ `secret` به‌عنوان یه اکشنِ Text جدا — secret باید **داخلِ همون فیلدهای فرم** باشه.

اگه بازم نشد، اپِ **[SMS Forwarder](https://apps.apple.com/us/app/sms-forwarder-forward-sms/id6693285061)** رو امتحان کن: مقصدِ فوروارد رو **URL** بذار و همون آدرسِ وب‌هوکت (`...sms.php?secret=...`) رو واردش کن.
