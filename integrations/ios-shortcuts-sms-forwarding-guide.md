# 📱 اتصال پیامک بانکی از آیفون

با یک **شورتکاتِ آماده**، پیامک‌های واریزِ بانکی خودکار به CubePay فرستاده می‌شن و فاکتورها لحظه‌ای تایید می‌شن — بدونِ هیچ اپِ جانبی.

> ⚠️ **دو مرحله داره و هر دو لازمه:** اول **شورتکات** رو اضافه می‌کنی، بعد یک **Automation** می‌سازی که همون شورتکات رو خودکار اجرا کنه. **بدونِ Automation هیچی کار نمی‌کنه.**
>
> 📱 گوشی‌ای که این روش روشه باید **همیشه روشن و به اینترنت وصل** باشه (پیامکِ بانک روی همون گوشی میاد).

---

## مرحله ۱ — شورتکات رو اضافه و آماده کن

۱. رو آیفون این لینک رو باز کن: **[افزودن شورتکاتِ CubePay](https://www.icloud.com/shortcuts/a22472a5fe254bb6a4c39414d490f2c0)** ← **Add Shortcut**. حالا توی **My Shortcuts** یه شورتکات به اسمِ **CubePay** داری.
۲. انگشتت رو روش نگه دار (یا سه‌نقطه‌ی بالاش) ← **Edit**. توی اکشنِ **Get Contents of URL**، آخرِ آدرس نوشته `PASTE_YOUR_CODE_HERE` — فقط همون رو پاک کن و **کدِ اتصالِ خودت** رو جاش بذار (کد رو از ربات، بخشِ «📲 روش تاییدیه مبلغ واریزی» می‌گیری). آدرسِ نهایی باید این بشه:
   `https://cubevps.ir/smspay/webhook/sms.php?secret=کدِ‌شما`
۳. بالا سمت راست **Done**.

## مرحله ۲ — Automation بساز و شورتکاتت رو بهش وصل کن

۱. اپ **Shortcuts** ← تب **Automation** ← **+** ← **Create Personal Automation**.
۲. نوعِ ماشه رو روی «پیامک» بذار (**اسمش بسته به نسخه‌ی iOS فرق می‌کنه**):
   - **iOSِ جدید:** **When I receive a message** — یه فیلترِ **Sender** داره که **اجباریه**؛ روش بزن و **شماره/سرشماره‌ی بانکت** (همونی که پیامکِ واریز ازش میاد) رو بذار.
   - **iOSِ قدیمی‌تر:** **When I Get a Message Containing…** — می‌تونی فرستنده‌ی بانک رو تو **From** بذاری، یا خالی بذاری.
۳. **مرحله‌ی آخر (مهم‌ترین قدم):** وقتی ازت می‌خواد اکشن انتخاب کنی، اکشنِ **Run Shortcut** رو اضافه کن و از **My Shortcuts** **همون شورتکاتِ CubePay که تو مرحله ۱ اضافه کردی** رو انتخاب کن. 👈 **همین‌جاست که شورتکاتت به Automation وصل می‌شه** — بدونِ این، Automation هیچ‌کاری نمی‌کنه.
۴. بالای صفحه **Ask Before Running** رو **خاموش** کن و ذخیره کن.

## تست

یه فاکتور بساز و مبلغِ کمی واریز کن؛ چند ثانیه بعد باید خودکار تایید بشه. برای عیب‌یابی، دکمه‌ی **«🧪 تست اتصال پیامک»** توی ربات هست.
