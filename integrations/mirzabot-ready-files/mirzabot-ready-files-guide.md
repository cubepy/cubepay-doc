# 📦 اتصال آماده‌ی CubePay به ربات Mirzabot (نصب با فایل، نه ویرایش دستی)

این راهنما برای فروشنده‌هاییه که ربات فروش‌شون رو با کد **Mirzabot**
(`mahdiMGF2/mirzabot`) ساختن. به‌جای این‌که خودتون خط‌به‌خط کد رو ویرایش کنید،
فقط فایل‌های آماده‌ی زیر رو دانلود و جایگزین کنید — سریع‌تر و بی‌خطاتر.

📁 دانلود فایل‌ها: [`mirzabot-cubepay-files.zip`](./mirzabot-cubepay-files.zip)

⚠️ **قبل از شروع:** یه نسخه پشتیبان (بک‌آپ) از پوشه‌ی ربات‌تون و از دیتابیس بگیرید.
این فایل‌ها **کامل جایگزین** فایل‌های فعلی می‌شن؛ اگه قبلاً خودتون یه درگاه دیگه یا
تغییر دیگه‌ای تو همین فایل‌ها داده باشید، از دست می‌ره.

## 🤖 نصب خودکار با `install.php` (اختیاری، به‌جای قدم ۲ و ۵)

داخل زیپ یه فایل `install.php` هم هست — یه ویزارد که هم از مرورگر (هاست اشتراکی/cPanel)
و هم از خط فرمان (`php install.php` — سرورهایی که SSH/VPS دارن) قابل اجراست، و به‌جای
جایگزینی دستی فایل‌ها + ورود توکن از داخل تلگرام، این کارها رو خودش انجام می‌ده:

- بک‌آپ گرفتن از فایل‌های فعلی قبل از جایگزینی
- کپی فایل‌های بخش ۱ (و در صورت انتخاب، بخش ۲) تو مسیرهای درست
- ثبت مستقیم توکن API و وضعیت فعال/غیرفعال تو جدول `PaySetting` (همون جدولی که
  `table.php` خودش می‌سازه) — بدون نیاز به ورود دستی از داخل تلگرام

### نحوه‌ی استفاده

1. زیپ رو اکسترکت کنید. قبل از آپلود، `install.php` رو باز کنید و مقدار
   `INSTALL_PASSWORD` رو به یه رمز دلخواه تغییر بدید.
2. یک‌بار پنل ادمین یا خود ربات رو (با فایل‌های فعلی، قبل از جایگزینی) باز کرده باشید
   تا `table.php` جدول `PaySetting` رو ساخته باشه — `install.php` به همین جدول نیاز داره.
3. همه‌ی فایل‌های اکسترکت‌شده (شامل `install.php`) رو جایی از هاست‌تون آپلود کنید.
4. **هاست اشتراکی/cPanel**: آدرس `install.php` رو تو مرورگر باز کنید و فرم رو پر کنید.
   **VPS با SSH**: بزنید `php install.php` و به سوال‌های تعاملی جواب بدید.
5. بعد از پیام موفقیت، همون لحظه `install.php` رو از روی سرور پاک کنید (دکمه‌ی حذف
   خودکار هم تو صفحه‌ی موفقیت هست).

⚠️ این اسکریپت فقط فایل‌های همین لیست رو جایگزین می‌کنه و فقط مقادیر شناخته‌شده‌ی
`PaySetting.merchant_token_cubepay` / `PaySetting.statuscubepay` رو می‌نویسه — هیچ کوئری
دلخواه دیگه‌ای اجرا نمی‌کنه. با این‌حال چون رمز دیتابیس رو مستقیم از شما می‌گیره، حتماً
رمز نصب رو عوض کنید و فایل رو بعد از اتمام کار پاک کنید. حداقل/حداکثر مبلغ و درصد
کش‌بک رو همچنان از داخل ربات تنظیم کنید (قدم ۵ پایین).

اگه ترجیح می‌دید همه‌چیز رو دستی انجام بدید، از قدم‌های زیر استفاده کنید.

## ✅ قدم‌های نصب دستی

### قدم ۱ — بک‌آپ
از کل پوشه‌ی ربات و دیتابیس یه کپی بگیرید.

### قدم ۲ — جایگزینی فایل‌ها روی هاست
زیپ رو دانلود و اکسترکت کنید، بعد فایل‌های بخش ۱ (و در صورت تمایل بخش ۲) رو دقیقاً
تو همون مسیرهای بالا، روی هاست/سرور خودتون جایگزین کنید (از طریق FTP، cPanel File
Manager، یا هر روشی که معمولاً فایل‌های ربات‌تون رو آپلود می‌کنید).

> 📌 اگه ربات‌تون رو از روی یه ریپوی گیت‌هاب اجرا می‌کنید و گیت هم ندارید،
> پایین همین صفحه بخش «جایگزینی از طریق خود گیت‌هاب (بدون نیاز به Git)» رو ببینید.

### قدم ۳ — اجرای یک‌بار جدول‌ساز
فایل `table.php` معمولاً موقع باز کردن پنل ادمین یا اجرای ربات به‌صورت خودکار صدا
زده می‌شه و ردیف‌های تنظیمات جدید (`statuscubepay`, `merchant_token_cubepay`, ...)
رو با `INSERT IGNORE` به جدول `PaySetting` اضافه می‌کنه — نیازی به دستور SQL دستی
نیست. فقط مطمئن شید بعد از جایگزینی فایل، یه‌بار پنل ادمین یا ربات رو باز کرده
باشید تا این ردیف‌ها ساخته بشن.

### قدم ۴ — ثبت‌نام تو CubePay و گرفتن توکن
اگه هنوز فروشنده نشدید، به [@cubepy_bot](https://t.me/cubepy_bot) پیام بدید، ثبت‌نام
کنید و بعد از تایید ادمین، توکن API‌تون رو از پنل فروشندگی بردارید.

### قدم ۵ — تنظیم توکن و فعال‌سازی تو ربات خودتون
تو ربات، برید به:

```
پنل مدیریت ← 💰 بخش مالی ← ردیف «🟣 کیوب‌پی»
```

- روی «⚙️ تنظیمات» بزنید و توکن API رو وارد کنید
- برگردید و روی وضعیت (روشن/خاموش) کنار همون ردیف بزنید تا روشن بشه
- در صورت نیاز حداقل/حداکثر مبلغ واریزی و درصد کش‌بک رو هم از همون منو تنظیم کنید

### قدم ۶ — تنظیم کارت و وب‌هوک پیامک تو CubePay
تو `@cubepy_bot`: «مدیریت کارت‌ها» → کارت خودتون رو ثبت کنید و طبق راهنمای همون
ربات، اپ فورواردر پیامک رو رو گوشی‌تون نصب و تنظیم کنید.

⚠️ گوشی‌ای که این اپ روشه باید همیشه به اینترنت وصل باشه، وگرنه هیچ تراکنشی خودکار
تایید نمی‌شه.

### قدم ۷ — تست
یه شارژ کیف‌پول کوچیک (مثلاً ۱۰,۰۰۰ تومان) امتحان کنید:
1. دکمه‌ی «🟣 کیوب‌پی» تو منوی شارژ حساب باید ظاهر بشه
2. با زدنش، لینک پرداخت CubePay براتون بیاد
3. بعد از واریز، ظرف چند ثانیه شارژ حساب خودکار انجام بشه و پیام تایید بیاد

## 🌐 جایگزینی از طریق خود گیت‌هاب (بدون نیاز به Git)

اگه ربات‌تون رو از روی یه فورک گیت‌هابی اجرا می‌کنید و ابزار Git رو رو کامپیوترتون
نصب ندارید، می‌تونید همه‌ی این کار رو مستقیم تو مرورگر، از داخل خود گیت‌هاب انجام
بدید:

1. وارد ریپوی خودتون بشید (مثلاً `github.com/USERNAME/mirzabot`).
2. **(پیشنهاد می‌شه)** یه شاخه‌ی (branch) جدید بسازید تا مستقیم روی `main` کار
   نکنید: بالای لیست فایل‌ها روی اسم شاخه (معمولاً `main`) کلیک کنید، یه اسم مثل
   `feature/cubepay-gateway` بنویسید و **Create branch** رو بزنید.
3. برای هر کدوم از فایل‌های **بخش ۱** (و بخش ۲ در صورت تمایل) که از قبل تو ریپو
   وجود دارن (`admin.php`, `index.php`, `function.php`, `keyboard.php`,
   `table.php`, `lang/fa.php`, `panel/payment.php`, `panel/user.php`,
   `cronbot/payment_expire.php`):
   - وارد پوشه‌ی مربوطه بشید و روی خود فایل کلیک کنید
   - آیکون مداد (**Edit this file**) رو بزنید
   - کل محتوا رو پاک کنید (Ctrl+A بعد Delete) و محتوای فایل جدید (از داخل زیپ) رو
     پیست کنید
   - پایین صفحه، روی **"Commit directly to the `<اسم شاخه‌ی شما>` branch"** رو
     انتخاب کنید و **Commit changes** بزنید
4. برای فایل **جدید** `payment/cubepay.php` (که از قبل وجود نداره): وارد پوشه‌ی
   `payment` بشید، **Add file → Create new file** رو بزنید، اسم `cubepay.php` رو
   بذارید، محتواش رو پیست کنید و commit کنید.
5. اگه از شاخه‌ی جدا استفاده کردید، حالا باید تو هاست‌تون هم مطمئن بشید همون
   شاخه دیپلوی می‌شه، یا یه Pull Request از این شاخه به `main` ریپوی خودتون بزنید
   و مرجش کنید.

## ❓ اگه فایل‌ها جواب نداد

اگه بعد از جایگزینی با خطا مواجه شدید، احتمالاً نسخه‌ی Mirzabot شما با نسخه‌ی
رسمی گیت‌هاب (شاخه‌ی `main`) که این فایل‌ها روش ساخته شده فرق داره — مثلاً قبلاً
خودتون یه‌جای دیگه‌ی همین فایل‌ها رو تغییر داده بودید یا یه درگاه دیگه اضافه کرده
بودید. در این حالت:

- بک‌آپ رو برگردونید
- کد `error_log` کنار فایل‌های PHP رو برای من بفرستید تا دقیق بررسی بشه
