# 📦 اتصال CubePay به Mirzabot

🎉 **این اتصال دیگه رسمی و مستقیم تو خودِ ریپوی Mirzabot ادغام شده** — دیگه نیازی به دانلود/جایگزینی فایل آماده از این پوشه نیست. این تغییر از طریق [PR #75 روی `mahdiMGF2/mirzabot`](https://github.com/mahdiMGF2/mirzabot/pull/75) merge شد و درگاه قدیمی Tronado رو با CubePay (کارت‌به‌کارت با تایید خودکار) جایگزین کرد.

## چیکار کنم؟

### 🆕 فروشنده‌ی تازه (نصب از صفر)
مستقیم از ریپوی رسمی Mirzabot (`mahdiMGF2/mirzabot`, برنچ `main`) نصب کنید — CubePay از قبل توشه، هیچ فایل اضافه‌ای لازم نیست. فقط:
1. تو ربات برید به: `پنل مدیریت ← 💰 بخش مالی ← ردیف «🟣 کیوب‌پی»`
2. روی «⚙️ تنظیمات» بزنید و توکن API (از [@cubepy_bot](https://t.me/cubepy_bot) → «🔗 پنل من») رو وارد کنید
3. وضعیت رو روشن کنید

برای گرفتن توکن و تنظیم کارت/وب‌هوک پیامک تو CubePay → `@cubepy_bot`: «مدیریت کارت‌ها» و راهنمای فورواردر پیامک.

### 🔁 فروشنده‌ای که هنوز نسخه‌ی قدیمی (Tronado) داره
کد رباتش رو از ریپوی رسمی آپدیت/pull کنه تا نسخه‌ی جدید (با CubePay داخلی) رو بگیره — قبلش حتماً از پوشه‌ی ربات و دیتابیس بک‌آپ بگیرید، چون آپدیت از upstream ممکنه تغییرات دیگه‌ای هم با خودش بیاره.

### ✅ فروشنده‌ای که قبلاً با فایل‌های آماده‌ی همین پوشه نصب کرده بود
نیازی به هیچ کاری نیست، رباتش همچنان درست کار می‌کنه — فقط لِیاوت فایلش (فایل جداگانه‌ی `payment/cubepay.php`) با نسخه‌ی رسمی ادغام‌شده (که به‌جاش `payment/tronado.php` رو بازنویسی کرده) یکی نیست. این تفاوت مشکلی ایجاد نمی‌کنه، مگر بخواید بعداً مستقیم از upstream یه `git pull` بگیرید که اون‌جا ممکنه نیاز به merge دستی باشه.
