# نصب به‌روزرسانی راهنمای تأیید مغایرت

این بسته فقط برای راهنمای موجود `/panel/help` است؛ نصب کامل راهنما یا تغییر منطق پرداخت نیست.

1. از فایل‌های فعلی `panel/help/panel.html`، `panel/help/faq.html`، `panel/help/troubleshooting.html` و `panel/help/assets/search-index.js` پشتیبان بگیرید.
2. [بستهٔ راهنما](../downloads/CubePay-Help-Mismatch-20261015.zip) را در `public_html` استخراج کنید و جایگزینی همین چهار فایل را بپذیرید. پوشهٔ `panel/help` را حذف نکنید.
3. اگر هاست یا CDN کش دارد، کش همین چهار فایل را پاک کنید. راهنما را با بارگذاری مجدد باز کنید و «مغایرت بدون رسید» را جست‌وجو کنید.
4. [بخش جدید راهنما](https://cubevps.ir/panel/help/panel.html#bank-mismatch-confirmation) باید مسیر ربات و مینی‌اپ و محدودیت‌ها را نمایش دهد.

فایل `.htaccess`، تنظیمات پنل، فایل‌های پرداخت و تصاویر/قالب راهنما دست‌نخورده می‌مانند. مسیرهای قبلی حفظ شده‌اند. بسته بر پایهٔ صفحات آنلاین دریافت‌شده در ۲۰۲۶-۱۰-۱۵ تهیه شده است؛ اگر بعد از این تاریخ این چهار فایل را اختصاصی تغییر داده‌اید، پیش از جایگزینی تفاوت‌ها را بررسی کنید.

محتوای راهنما: [تأیید مغایرت بدون رسید](MISMATCH-CONFIRMATION.md). تا زمان آپلود بسته، تغییر گیت‌هاب به‌تنهایی راهنمای روی هاست را تغییر نمی‌دهد.
